# TAIMIO

**Слоган:** «Не пересматривай. Найди.»

TAIMIO — настольное приложение для анализа длинных видеоматериалов. Оно превращает видео в локально сохранённую базу знаний: полную расшифровку с таймкодами, структурированный конспект, смысловой поиск по одному или нескольким видео и подбор важных визуальных материалов.

## Что лежит в стартовом пакете
- `START_HERE.md` — обязательный порядок работы Cursor.
- `TAIMIO_TZ.md` — подробное техническое задание MVP.
- `design/` — утверждённые визуальные референсы.

## Целевая платформа MVP
Windows desktop.

## Принцип приватности
Проект предусматривает два способа анализа: облачный AI через API-ключ пользователя и полностью локальный режим. Исходные видео должны оставаться локальными; приложение обязано ясно показывать пользователю, какие данные могут передаваться внешнему AI-провайдеру.
