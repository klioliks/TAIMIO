# TAIMIO — START HERE

Это стартовый пакет проекта TAIMIO.

## Главный принцип работы
Разработка ведётся ПОЭТАПНО. Cursor не должен пытаться реализовать весь проект одним большим изменением.

Порядок:
1. Полностью прочитать этот файл.
2. Полностью прочитать `TAIMIO_TZ.md`.
3. Изучить все утверждённые изображения в `/design`.
4. Прочитать `README.md`.
5. Предложить архитектуру и план реализации, но НЕ писать код до явного разрешения пользователя.
6. После разрешения реализовывать только один согласованный этап за раз.
7. После каждого этапа: запустить проверки, исправить ошибки, кратко описать сделанное и дать пользователю понятную инструкцию проверки.
8. Ждать разрешения переходить к следующему этапу.

## Утверждённые дизайн-референсы
- `design/taimio-logo.png` — утверждённый логотип/иконка и визуальная идентика TAIMIO.
- `design/taimio-welcome-screen.png` — утверждённое направление стартового экрана.
- `design/taimio-workspace-background.png` — утверждённое направление рабочей области.

Не заменять фирменную концепцию случайным шаблонным UI. Допустима адаптация референсов под реальные компоненты, читаемость, масштабирование и доступность.

## Важное
TAIMIO должен ощущаться для конечного пользователя как обычная Windows-программа: установка, ярлык, двойной клик, графический интерфейс. Пользователь не должен запускать Python, терминал, npm-команды или Cursor.
